# ColorVision 2.0

Камераар өнгө таних, өнгөний ой тогтоолтоо сорих, өөрийн өнгийг үүсгэн хадгалах зориулалттай Python desktop аппликейшн. Интерфэйсийг CustomTkinter, камерын дүрс боловсруулалтыг OpenCV ашиглан хийсэн. Аппын товч, цэсүүд англи хэлтэй.

## Үндсэн боломжууд

| Горим | Боломжууд |
| --- | --- |
| **Camera Mode** | Камерын төв хэсэг эсвэл хулганаар сонгосон цэгийн орчмын өнгийг таних; нэр, HEX, RGB, HSV харуулах; өнгийг тогтоож нэрлэн хадгалах; камерын зураг авах. |
| **Game Mode** | Өнгийг цээжлээд дахин сонгох 5 үе бүхий тоглоом; үе тус бүрийн болон нийт оноо; шилдэг оноо, сүүлийн тоглолтууд. |
| **Color Picker** | Hue, Saturation, Brightness тохируулж эсвэл HEX оруулж өнгө үүсгэх; нэрлэн хадгалах; хадгалсан өнгийг дахин сонгох, устгах. |
| **History** | Хадгалсан өнгө, камерын танилтын түүх, тоглоомын үр дүнг тусдаа табаар үзэх; хайх; хадгалсан өнгийн нэрийг өөрчлөх, устгах; танилтын түүхийг цэвэрлэх. |

## Шаардлага

- **Windows**: камерын одоогийн код `cv2.CAP_DSHOW` буюу Windows-ийн DirectShow ашигладаг. Бусад үйлдлийн системд камер ашиглахын тулд backend-ийг өөрчлөх шаардлагатай.
- **Python 3.10 буюу түүнээс шинэ хувилбар**, `pip`, Tkinter/Tcl/Tk дэмжлэгтэй Python суулгалт.
- **Вэб камер**, камер ашиглах системийн зөвшөөрөл — Camera Mode-д хэрэгтэй.
- Аппын цонхны хамгийн бага хэмжээ **950 × 650**, анхны хэмжээ **1100 × 750**.
- Төслийн `data/`, `screenshots/` хавтаст бичих эрх.

Камергүй үед Color Picker, Game Mode, History горимуудыг ашиглаж болно. Багцуудыг анх суулгахад интернет хэрэгтэй; апп ажиллахдаа сервер, API түлхүүр, тусдаа өгөгдлийн сан шаардахгүй.

## Суулгах, ажиллуулах

Төслийг татаж задлаад Windows PowerShell дээр төслийн үндсэн хавтас руу орно:

```powershell
cd "C:\path\to\ColorVision 2.0"
```

`C:\path\to\ColorVision 2.0` хэсгийг өөрийн төслийн замаар солино.

Виртуал орчин үүсгэж, шаардлагатай багцуудыг суулгана:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Аппыг ажиллуулна:

```powershell
.\.venv\Scripts\python.exe main.py
```

Эдгээр команд виртуал орчны Python-ийг шууд ашигладаг тул орчныг тусад нь идэвхжүүлэх шаардлагагүй. `python` команд олдохгүй бол виртуал орчин үүсгэхдээ `py -3 -m venv .venv` ашиглаж болно.

### Ашигласан сангууд

| Багц | Үүрэг |
| --- | --- |
| `customtkinter` | Үндсэн цонх, товч, slider, таб болон бусад интерфэйс. |
| `numpy` | Камерын дүрсний массив, өнгийн сувгуудын медиан тооцоолол. |
| `opencv-python` | Камер унших, RGB/HSV/Lab хөрвүүлэлт, дүрс дээр тэмдэглэгээ хийх, PNG хадгалах. |
| `Pillow` | Дүрсийг интерфэйст харуулах, хэмжээг өөрчлөх, тоглоомын өнгө сонгогчийн градиент үүсгэх. |

`tkinter`, `json`, `pathlib`, `datetime`, `colorsys`, `math` зэрэг нь Python-ийн стандарт сангууд тул `requirements.txt`-ээр суулгахгүй. Tkinter байхгүй бол Python суулгагчийн Tcl/Tk бүрэлдэхүүнийг нэмнэ.

## Хэрэглэх заавар

### Camera Mode

1. Dashboard-оос **Camera Mode → Open Mode** сонгоод **Start** дарна.
2. Анх камерын дүрсний төв хэсгийн өнгийг танина. Дүрсэн дээр дарвал тухайн цэгийн орчмын өнгийг таних горимд шилжинэ. **Mode** товчоор төвийн болон сонгосон цэгийн горимыг сольж болно.
3. Баруун талд өнгийн нэр, HEX, RGB, HSV болон нэрийг хэрхэн тодорхойлсныг харуулна: **Automatic** эсвэл **Saved Color**.
4. Өнгө хадгалахын тулд **Freeze Color** дарж, нэр оруулаад **Save Frozen Color** дарна. Энэ үед өнгийн утгыг тогтоох бөгөөд камерын дүрс үргэлжлэн шинэчлэгдэнэ. **Resume Detection** товчоор танилтыг үргэлжлүүлж болно.
5. **Screenshot** дарвал камерын тухайн кадрыг `screenshots/color_YYYYMMDD_HHMMSS_ffffff.png` нэртэй хадгална.
6. **Stop** камераа зогсооно. **Dashboard** руу буцахад камер мөн хаагдана.

Өнгийг нэг пикселээс бус, сонгосон хэсгийн RGB сувгуудын медианаар тооцоолдог. Эхлээд хадгалсан өнгүүдтэй Lab орон зайд харьцуулж, хангалттай ойр өнгө байвал хадгалсан нэрийг хэрэглэнэ. Бусад тохиолдолд HSV-ийн босго утгуудаар үндсэн өнгийн нэрийг тодорхойлно.

Нэг нэр дараалан 3 удаа илэрвэл танилтыг тогтворжуулна. Тогтворжсон өнгийн нэр өмнөх бүртгэлээс өөр болж, сүүлийн бүртгэлээс дор хаяж 3 секунд өнгөрсөн үед танилтын түүхэнд автоматаар нэмнэ. Камерын HSV утгууд OpenCV-ийн хэмжээсээр харагдана: **H: 0–179, S/V: 0–255**.

### Game Mode

1. **START GAME** дарна.
2. Үе бүрд харуулсан өнгийг **5 секунд** цээжилнэ.
3. Дараагийн **7 секундэд** өнгө сонгогчоор ижил өнгийг бүтээж **SUBMIT COLOR** дарна. Хугацаа дуусвал одоо сонгосон өнгөөр автоматаар дүгнэнэ.
4. Зорилтот болон сонгосон өнгө, тухайн үеийн оноог харьцуулж үзээд **NEXT ROUND** дарна.
5. Нийт **5 үе** тоглоно. Тав дахь үеийн дараа мөн **NEXT ROUND** дарж тоглоомыг дуусгахад үр дүн хадгалагдана. Дахин тоглохдоо **PLAY AGAIN** дарна.

Үе бүрийн оноо **0–100**, нийт дээд оноо **500**. Оноог зорилтот болон сонгосон өнгийн RGB утгуудын Евклидийн зайгаар тооцно; яг ижил өнгө 100 оноотой. Зөвхөн дуусгасан тоглолтууд түүхэнд хадгалагдана.

### Color Picker

1. **Hue**, **Saturation**, **Brightness** slider-уудаар өнгөө тохируулна.
2. Эсвэл 6 оронтой HEX утга (`#AABBCC` эсвэл `AABBCC`) оруулаад **Apply HEX** дарна.
3. Өнгийн нэр оруулаад **Save Color** дарж хадгална.
4. **SAVED COLORS** жагсаалтын **Use** товчоор өнгийг дахин сонгож, **×** товчоор устгана.

Энд хадгалсан өнгүүдийг Camera Mode мөн нэр тааруулахдаа ашиглана.

### History

- **Saved Colors**: нэр эсвэл HEX-ээр хайх; **Rename** товчоор нэрийг өөрчлөх; **Delete** товчоор устгах.
- **Detection History**: камерын бүртгэлүүдийг үзэх, нэр эсвэл HEX-ээр хайх, нэг бүрчлэн устгах. **Clear History → Delete All** үйлдлээр танилтын түүхийг бүхэлд нь цэвэрлэнэ.
- **Game History**: тоглосон огноо, нийт оноо, 5 үеийн оноо, шилдэг оноог харах; огноо эсвэл нийт оноогоор хайх.
- **Refresh** товчоор мэдээллийг дахин уншина.

## Өгөгдөл хадгалалт

Бүх бүртгэл төслийн `data/` хавтаст UTF-8 JSON хэлбэрээр хадгалагдана.

| Файл | Агуулга |
| --- | --- |
| `data/colors.json` | Хэрэглэгчийн нэрлэн хадгалсан өнгүүд: `name`, `rgb`, `hex`. |
| `data/history.json` | Камерын танилтын түүх: `id`, `name`, `rgb`, `hex`, `source`, `timestamp`. Хамгийн сүүлийн **500** бүртгэлийг хадгална. |
| `data/game_history.json` | Дууссан тоглолтууд: `date`, `total_score`, `max_score`, `round_scores`. |
| `screenshots/*.png` | Screenshot товчоор авсан камерын кадрууд. |

JSON файлууд байхгүй бол унших үед автоматаар хоосон жагсаалттай үүсгэнэ. `screenshots/` хавтсыг анхны зураг хадгалах үед үүсгэнэ. Өгөгдлийн замыг кодын байршлаас тооцдог. Огноо, цагийг тухайн компьютерийн орон нутгийн цагаар бүртгэнэ.

Өгөгдлөө нөөцлөхдөө `data/` болон `screenshots/` хавтсыг хуулж авна.

## Төслийн бүтэц

```text
ColorVision 2.0/
├── main.py                     # Аппын эхлэл, цонх, хуудас хоорондын шилжилт
├── requirements.txt            # Шууд ашигладаг Python багцууд
├── README.md
├── core/
│   ├── __init__.py
│   ├── color_analyzer.py       # HEX/RGB, luminance, contrast тооцох туслах функцууд
│   ├── color_detector.py       # Дүрсний хэсгээс өнгө болон HSV нэр тодорхойлох
│   ├── color_matcher.py        # Хадгалсан өнгө удирдах, Lab зайгаар нэр тааруулах
│   ├── game_engine.py          # Санамсаргүй өнгө үүсгэх, оноо тооцох
│   ├── game_history.py         # Тоглолтын үр дүн, шилдэг оноо
│   └── history_store.py        # Камерын танилтын түүх хадгалах, устгах
├── gui/
│   ├── __init__.py
│   ├── dashboard.py            # Үндсэн цэс
│   ├── camera_page.py          # Камерын горим
│   ├── game_page.py            # Өнгө цээжлэх тоглоом
│   ├── color_picker_widget.py  # Тоглоомын өнгө сонгогч
│   ├── picker_page.py          # Өнгө үүсгэх, хадгалах хуудас
│   └── history_page.py         # Өнгө болон тоглолтын түүх
├── data/
│   ├── colors.json
│   ├── history.json
│   └── game_history.json
└── screenshots/               # Камерын хадгалсан зургууд; шаардлагатай үед үүснэ
```

`core/color_analyzer.py` нь туслах модуль бөгөөд одоогийн GUI-ээс дуудагдахгүй.

## Түгээмэл асуудал

| Асуудал | Шалгах зүйл |
| --- | --- |
| `ModuleNotFoundError` | Апп ажиллуулах Python орчиндоо `.\.venv\Scripts\python.exe -m pip install -r requirements.txt` командыг ажиллуулсан эсэх. |
| `No module named tkinter` / `_tkinter` | Python суулгагчийн Tcl/Tk бүрэлдэхүүнийг суулгах. `python -m tkinter` командаар Tkinter-ийн туршилтын цонх нээгдэх эсэхийг шалгаж болно. |
| `CAMERA ERROR` | Камер холбогдсон эсэх, Windows-ийн камерын нууцлалын тохиргоонд desktop аппын хандалт зөвшөөрөгдсөн эсэх, өөр программ камер ашиглаж байгаа эсэх. |
| Өөр камер сонгох хэрэгтэй | `gui/camera_page.py` файлын `start_camera()` доторх `cv2.VideoCapture(0, cv2.CAP_DSHOW)`-ийн `0` индексийг тухайн камерын индексээр солих. Камер сонгох UI одоогоор байхгүй. |
| Танигдсан өнгө бодит өнгөөс зөрөх | Гэрэлтүүлэг, сүүдэр, камерын exposure болон white balance нөлөөлнө. Жигд гэрэлд туршиж, шаардлагатай өнгөө нэрлэн хадгалах. |
| Түүх, өнгө, зураг хадгалагдахгүй | Төслийн хавтаст бичих эрх болон дискний сул зайг шалгах. |

## Суулгалтыг шалгах

```powershell
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -c "import customtkinter, cv2, numpy; from PIL import Image, ImageTk; import main; print('Imports OK')"
```

Дараа нь аппыг нээж дөрвөн горимд шилжих, камер асаах, өнгө хадгалах, тоглоом дуусгах, түүх шинэчлэгдэхийг шалгана. Төсөлд одоогоор автомат тестийн багц байхгүй.
